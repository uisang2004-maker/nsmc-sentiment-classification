## 1. 자연어 처리 모델의 기본 개념

| 용어 | 뜻 |
|---|---|
| 딥러닝 기반 자연어 처리 모델 | GPT, BERT처럼 딥러닝으로 자연어를 처리하는 모델 |
| 학습 데이터 | 정답 레이블을 달아 놓은 데이터 |
| 학습 | 모델이 학습 데이터의 패턴을 익히도록 가중치를 업데이트하는 과정 |
| 트랜스퍼 러닝 | 한 태스크로 학습한 모델을 다른 태스크에 재사용하는 것 |
| 자기지도 학습 | 데이터 안에서 정답 레이블을 스스로 만들어 학습하는 방식 (예: 다음 단어 맞히기) |
| 파인튜닝 | 프리트레인을 마친 모델을 다운스트림 태스크 데이터에 맞게 추가로 업데이트하는 것 |

### 업스트림과 다운스트림

- **업스트림 태스크(프리트레인)**: 대량의 텍스트로 언어 자체를 배우는 단계
  - 다음 단어 맞히기 → **언어 모델** (GPT)
  - 빈칸 맞히기 → **마스크 언어 모델** (BERT)
- **다운스트림 태스크**: 실제로 풀고 싶은 문제 (문서 분류, 개체명 인식, 질의응답 등)

### 다운스트림 태스크 학습 방식

| 방식 | 사용하는 데이터 | 업데이트하는 범위 |
|---|---|---|
| 파인튜닝 | 다운스트림 데이터 전체 | 모델 전체 |
| 프롬프트 튜닝 | 다운스트림 데이터 전체 | 모델 일부 |
| 인컨텍스트 러닝 | 다운스트림 데이터 일부 (프롬프트 속 예시) | 업데이트하지 않음 |

### 학습 파이프라인

```
설정값(하이퍼파라미터) 정하기
 → 다운스트림 데이터 내려받기 (예: 영화 리뷰)
 → 프리트레인 모델 불러오기
 → 토크나이저 준비 (BPE 또는 워드피스)
 → 데이터 로더 준비
 → 태스크 정의 (모델, 옵티마이저, 손실 함수)
 → 학습 실행
```

- **데이터 로더**: 데이터셋을 배치 단위로 묶어 모델에 넣어 주는 역할. 샘플들을 텐서 배치로 합치는 과정을 **콜레이트(collate)** 라고 함
- 책은 학습 실행을 PyTorch Lightning의 Trainer에 맡기지만, 이 저장소에서는 학습 루프를 직접 작성함

## 2. 토큰화

**토큰화**: 문장을 토큰 시퀀스로 나누는 것. 넓은 의미로는 품사 부착 같은 처리까지 포함함

| 단위 | 특징 |
|---|---|
| 단어 | 의미가 잘 보존되지만 어휘 집합이 매우 커짐 |
| 문자 | 어휘 집합은 작지만 토큰 하나의 의미가 약하고 시퀀스가 길어짐 |
| 서브워드 | 둘의 절충. 자주 쓰는 단어는 통째로, 드문 단어는 조각으로 나눔 → **BPE**(GPT), **워드피스**(BERT) |

### BPE (Byte Pair Encoding)

가장 자주 함께 등장하는 문자열 쌍을 반복해서 병합하는 방식. 어휘 집합 크기를 억제하면서 정보를 압축함

**어휘 집합 만들기**

1. 프리토크나이즈: 말뭉치의 모든 문장을 공백 기준으로 나누고 단어별 빈도 세기
2. 모든 단어를 문자 단위로 나눈 뒤, 인접한 두 토큰(바이그램) 쌍의 빈도 세기
3. 가장 많이 나온 쌍을 하나로 병합하고 병합 규칙에 기록
4. 사용자가 정한 어휘 집합 크기가 될 때까지 2~3 반복
5. 결과: 어휘 집합(`vocab.json`)과 병합 우선순위(`merges.txt`)

**토큰화하기**: 문장을 문자 단위로 나눈 뒤 `merges.txt`의 우선순위대로 병합. 어휘 집합에 없는 토큰은 미등록 토큰(`<unk>`)으로 처리

### 워드피스 (WordPiece)

병합했을 때 말뭉치의 **우도(likelihood)** 를 가장 크게 높이는 쌍을 병합하는 방식

$$\text{score}(a, b) = \frac{P(ab)}{P(a) \cdot P(b)}$$

a와 b가 각각 자주 나오는 것에 비해 **함께** 나오는 경우가 많을수록 점수가 높음

**토큰화하기**: 어휘 집합(`vocab.txt`)만 사용

1. 어절에서 어휘 집합에 있는 **가장 긴 서브워드**를 앞에서부터 분리
2. 남은 부분에서 다시 가장 긴 서브워드 분리 (단어 중간 조각에는 `##`이 붙음)
3. 어휘 집합에 맞는 서브워드가 하나도 없으면 그 어절 전체를 미등록 토큰(`[UNK]`)으로 처리

### 실습 정리

- **어휘 집합 구축**: NSMC 리뷰를 텍스트 파일로 저장한 뒤, Hugging Face `tokenizers`의 `ByteLevelBPETokenizer`(BPE)와 `BertWordPieceTokenizer`(워드피스)로 각각 학습해 어휘 집합 생성
- **토큰화**: `GPT2Tokenizer`, `BertTokenizer`로 문장을 토큰화

| 입력 옵션 | 의미 |
|---|---|
| `padding="max_length"` | `max_length`까지 패딩 토큰으로 채움 |
| `max_length` | 토큰 기준 최대 길이 |
| `truncation=True` | 최대 길이를 넘으면 자름 |

| 출력 | 의미 |
|---|---|
| `input_ids` | 각 토큰의 어휘 집합 인덱스 |
| `attention_mask` | 일반 토큰(1)과 패딩 토큰(0) 구분 |
| `token_type_ids` | (BERT) 문장 두 개를 입력할 때 첫 문장은 0, 둘째 문장은 1로 구분하는 세그먼트 정보 |

## 3. 언어 모델과 트랜스포머

### 언어 모델

**언어 모델**: 단어 시퀀스에 확률을 부여하는 모델. 이전 단어들이 주어졌을 때 다음 단어가 나올 확률을 계산함

- **조건부 확률**: A가 주어졌을 때 B가 나올 확률

$$P(B \mid A) = \frac{P(A, B)}{P(A)}$$

- **결합 확률**: 단어 여러 개가 동시에 나타날 확률. 조건부 확률의 곱으로 분해할 수 있음 (연쇄 법칙)

$$P(w_1, w_2, w_3, \dots) = P(w_1) \cdot P(w_2 \mid w_1) \cdot P(w_3 \mid w_1, w_2) \cdots$$

| 종류 | 학습 방식 |
|---|---|
| 순방향 언어 모델 | 앞에서부터 다음 단어 맞히기 (사람이 읽는 순서). GPT |
| 역방향 언어 모델 | 문장 끝에서부터 이전 단어 맞히기 |
| 마스크 언어 모델 | 문장 중간의 빈칸 맞히기. 앞뒤 문맥을 모두 봄(양방향). BERT |
| 스킵-그램 | 특정 단어의 앞뒤 일정 범위 안에 어떤 단어가 오는지 맞히기. Word2Vec |

### 트랜스포머

시퀀스를 다른 시퀀스로 바꾸는 **시퀀스-투-시퀀스** 태스크(예: 번역)에 특화된 모델

| 구성 | 역할 | 입력 |
|---|---|---|
| 인코더 | 소스 시퀀스의 정보를 압축해 디코더로 전달 | 소스 시퀀스 전체 |
| 디코더 | 인코더 정보를 받아 타깃 시퀀스를 생성 | 타깃 시퀀스의 일부 |

- **출력**: 타깃 언어의 어휘 수만큼의 차원을 가진 확률 벡터 (각 요소 = 그 단어가 다음 단어일 확률)
- **학습**: 정답 단어에 해당하는 확률을 높이는 방향으로 업데이트. 디코더에는 맞혀야 할 단어 **이전까지의 정답** 타깃 시퀀스를 넣음
- **인퍼런스**: 디코더에 **직전까지 자신이 생성한 결과**를 넣어 한 단어씩 생성

### 셀프 어텐션

- **어텐션**: 중요한 요소에 더 큰 가중치를 줘서 집중하는 기법
- **셀프 어텐션**: 입력 시퀀스가 자기 자신에게 수행하는 어텐션. 각 단어가 문장 안의 모든 단어와의 관계를 고려해 문맥을 반영한 표현을 만듦

| 구조 | 한계 |
|---|---|
| 합성곱 신경망(CNN) | 필터 크기 안의 지역적 특징만 봄. 먼 단어와의 관계를 잡기 어려움 |
| 순환 신경망(RNN) | 순서대로 처리해서 시퀀스가 길어지면 앞의 정보를 잊음 |
| 셀프 어텐션 | 모든 단어 쌍의 관계를 한 번에 계산해서 거리와 상관없이 문맥 전체를 고려 |

**계산 과정**

입력 X는 토큰 ID를 768차원 같은 실수 벡터로 바꾼 **임베딩**에 **위치 정보**를 더한 것. 이 X에 서로 다른 가중치 행렬을 곱해 세 벡터를 만듦

$$Q = XW_Q, \quad K = XW_K, \quad V = XW_V$$

| 벡터 | 역할 |
|---|---|
| 쿼리 Q | 지금 단어가 다른 단어들에게 던지는 질문 |
| 키 K | 각 단어가 쿼리와 얼마나 관련 있는지 비교되는 기준 |
| 밸류 V | 각 단어에서 실제로 가져올 정보 |

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

1. Q와 K의 내적으로 단어 간 관련도 점수 계산
2. $\sqrt{d_k}$로 나눠 값이 너무 커지지 않게 조정
3. softmax로 점수를 합이 1인 확률(가중치)로 변환
4. 그 가중치로 V를 가중합

**멀티 헤드 어텐션**: 셀프 어텐션을 여러 개(헤드) 병렬로 수행해 서로 다른 관점의 관계를 학습. 모든 헤드의 출력을 이어 붙인 뒤 가중치 행렬 $W_O$를 곱해 (입력 단어 수 × 모델 차원) 크기로 만듦

| 종류 | 특징 |
|---|---|
| 인코더 셀프 어텐션 | 소스 시퀀스의 모든 단어 쌍 관계를 고려 |
| 디코더 셀프 어텐션 | 정답을 미리 보지 않도록 **현재 위치보다 뒤의 단어를 마스킹**하고 수행 (마스크드 멀티 헤드 어텐션) |

### 트랜스포머 블록의 나머지 구성

| 구성 | 역할 |
|---|---|
| 피드포워드 뉴럴넷 | 입력층, 은닉층, 출력층으로 구성. 가중합에 활성화 함수를 적용 |
| 잔차 연결 | 블록의 계산을 건너뛰는 경로를 더함 $F(x) + x$. 층이 깊어도 학습이 잘 되게 함 |
| 레이어 정규화 | 각 입력 벡터마다 평균 0, 분산 1로 정규화해 학습을 안정화 |

### 모델 학습 용어

| 용어 | 뜻 |
|---|---|
| 순전파 | 입력부터 출력까지 순서대로 계산해 예측값과 손실을 구함 |
| 역전파 | 손실을 출력층에서 입력층 방향으로 거꾸로 전달하며 각 가중치의 그레디언트 계산 |
| 연쇄 법칙 | 역전파에서 파라미터별 그레디언트를 구할 때 쓰는 미분 법칙 |
| 그레디언트 | 손실을 줄이려면 가중치를 어느 방향으로 바꿔야 하는지 나타내는 값 |
| 러닝 레이트 | 가중치를 한 번 업데이트할 때의 보폭. 스케줄러로 학습 중에 조정함 |
| 아담 옵티마이저 | 그레디언트와 보폭을 파라미터마다 적응적으로 조절하는 최적화 도구 |
| 드롭아웃 | 학습 중 일부 값을 무작위로 0으로 바꿔(보통 p=0.1) 과적합(학습 데이터를 외워 버리는 현상)을 방지 |

### GPT와 BERT

| | GPT | BERT |
|---|---|---|
| 구조 | 트랜스포머의 **디코더**만 사용 | 트랜스포머의 **인코더**만 사용 |
| 어텐션 | 마스크드 멀티 헤드 어텐션 (뒤 단어를 가림) | 멀티 헤드 어텐션 (앞뒤를 모두 봄) |
| 프리트레인 | 다음 단어 맞히기 | 빈칸 맞히기 |
| 잘하는 일 | 문장 생성 | 문장·단어의 의미 파악 (분류, 개체명 인식 등) |

### 문장 벡터와 단어 벡터

BERT는 문장을 워드피스로 토큰화하고 앞뒤에 `[CLS]`, `[SEP]` 토큰을 붙여 입력함

| | 문장 벡터 | 단어 벡터 |
|---|---|---|
| 쓰는 출력 | `[CLS]` 위치의 벡터를 한 번 더 가공한 `pooler_output` (문장 전체 의미가 응집됨) | 모든 토큰 위치의 벡터 시퀀스 |
| 활용 태스크 | 문서 분류 | 개체명 인식 |

## 4. 문서 분류 모델

### 모델 구조

```
문장 → 토큰화 + [CLS], [SEP] 추가 → BERT → pooler_output
     → 드롭아웃 → 선형 층(768 → 2) → softmax → [부정 확률, 긍정 확률]
```

- 출력 확률을 정답 레이블과 비교해 손실을 계산하고, BERT 본체와 분류 층을 **함께** 업데이트 (파인튜닝)

### 실습 흐름

1. 설정값(하이퍼파라미터) 정하기
2. NSMC 데이터 내려받기, 빈 리뷰 제거, 학습/검증 분리
3. 토크나이저 준비
4. 학습·검증·테스트 데이터셋과 데이터 로더 준비
5. 모델, 옵티마이저, 학습률 스케줄러 준비
6. 학습 루프 실행 후 테스트 평가

**주요 하이퍼파라미터**

| 항목 | 값 | 의미 |
|---|---|---|
| `model_name` | `beomi/kcbert-base` | 사전학습 모델 |
| `max_length` | 128 | 문장을 최대 몇 토큰까지 볼지 |
| `batch_size` | 32 | 한 번에 학습하는 문장 수 |
| `learning_rate` | 5e-5 | 파인튜닝에서 흔히 쓰는 작은 학습률 |
| `epochs` | 1 | 전체 데이터를 몇 번 반복할지 |
| `warmup_ratio` | 0.1 | 처음 10% 스텝 동안 학습률을 0에서 천천히 올림 |

자세한 구현과 결과는 [노트북](../nsmc_kcbert_classification.ipynb)과 [README](../README.md)를 참고

## 부록: NLP에서 자주 쓰는 pandas 함수

### 데이터 읽기·저장

| 함수 | 용도 | 예시 |
|---|---|---|
| `pd.read_csv()` | CSV·TSV 파일 읽기 | `pd.read_csv("data.tsv", sep="\t")` |
| `pd.read_json()` | JSON 파일 읽기 (한 줄에 하나씩이면 `lines=True`) | `pd.read_json("data.jsonl", lines=True)` |
| `df.to_csv()` | 전처리 결과 저장 | `df.to_csv("clean.csv", index=False)` |

### 데이터 살펴보기 (EDA)

| 함수 | 용도 | 예시 |
|---|---|---|
| `df.head()` / `df.sample()` | 앞부분 / 무작위로 몇 줄 보기 | `df.sample(5)` |
| `df.shape` | 행·열 개수 | `(150000, 3)` |
| `df.info()` | 칸별 자료형, 빈 값 개수 | `df.info()` |
| `df.describe()` | 숫자 통계 요약 | `df["document"].str.len().describe()` |
| `value_counts()` | 값별 개수 (레이블 불균형 확인) | `df["label"].value_counts()` |
| `isna().sum()` | 칸별 빈 값 개수 | `df.isna().sum()` |

### 선택·필터링

| 함수 | 용도 | 예시 |
|---|---|---|
| `df["칸"]` | 칸 하나 꺼내기 | `df["document"]` |
| `.iloc[]` | 위치로 꺼내기 | `df.iloc[0]` |

| 조건 필터 | 조건에 맞는 줄만 남기기 | `df[df["document"].str.len() > 5]` |

### 정제

| 함수 | 용도 | 예시 |

### 문자열 처리 (`.str`)
